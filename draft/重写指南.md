# 《灵潮修仙录》全卷重写指南（草稿）

范围：保留人物、世界观、每卷主线和五种终章；重写章节叙述、对白和选项。
状态：草稿，未接入构建，不改动 `src/`。存档兼容方案在替换线上文件前再定。

## 一、文笔规则

1. **口癖限额**：下面这些句式，每章最多各出现一次，整卷也不堆叠。
   - 「没有……也没有……」「不是 A，是 B」「没说话 / 没替他……」「过了很久 / 过了许久」。
   - 想表达“他沉默了”，改写成一个具体动作或一个具体的东西。
2. **不替读者下结论**：删掉“接受帮助和原谅是两件事”这类总结句，让对白和动作自己说。
3. **说明换成动作**：规程、方案、术语（信号绳、归相钉、供电方案）不整段讲。
   用一个人的操作、一次失误、一句争吵带出来，术语每段不超过两个。
4. **操作提示移出剧情**：【江湖页点地面行走……】【迎战：……】、“换一条路试试”这类话，
   统一放到界面提示层，剧情文字里只留世界内的说法。
5. **人物各有一种说话的办法**：阿禾、苏绾、墨老、萧尘不能都在讲“留白、标注不确定”。
   给每人定一个习惯（墨老毒舌短句，萧尘爱把话说到一半，阿禾先问数，苏绾先问人）。
6. **保留强项**：用物件和小动作写情绪，不直说。这是全稿最好的东西，不要改掉。

## 二、节奏规则

1. **每卷前三章之内必须出现一个冲突或悬念**。“开会、准备、测量”类章节合并，一卷里连续的准备章不超过两章。
2. **一章一个目的**：一章要么推进冲突，要么落一个情感点，要么揭一层真相，不三样都塞。
3. **卷尾要收束**：每卷至少解决一条线，同时留下下一卷的钩子，不再只剩“小物件加一句淡话”。
4. **终章不写成通报**：用一个具体画面收尾，不把每个人的去向列成清单。

## 三、选项规则

1. **禁止假选择**：两个选项的回应台词不能相同。每个选项至少要有
   - 一句不同的当场台词，并且
   - 一个会被后文读取的变量。
2. **写入必有读取**：每个 `flag` 写入时，必须在后面某卷有至少一处读取（台词分支、因果录、结局差异）。
   重写完每卷后用 grep 校验，找不到读取者的变量要么补上，要么删掉那个选项。
3. **预告代价**：选项文字里要让人看得出“要付什么”（时间、寿元、关系、物资），但不写出“正确答案”。
   两个选项都要“听着合理”。
4. **善恶标记（k）重新定义**：k 只表示道德后果；冒进、风险用单独的标记，不混用。
5. **终章差异**：五种终章各自独立成篇，且前两组岔章（丹方、旧案）在每条路线上都要有可见痕迹。
   bai（白塔长明）的触发条件要在前几卷有暗示，不能事后才知道。

## 四、流程

1. 每次只重写一卷（或一卷的前半），写成独立草稿文件，放在 `draft/` 里。
2. 你过目、提意见、我改完，再写下一卷。
3. 每卷交稿时同时给：
   - 本卷章节清单与每章目的；
   - 本卷选择变量表（谁写入、谁读取）；
   - 与旧稿的主要差别。
4. 全部定稿后，再统一做：存档迁移方案 → 替换 `src/` → 运行 `build.py` → 跑 `test-game.cjs` 和 `test-art.cjs`。

- 节奏：第二卷偏长，第五卷中段循环，第十卷前 4 章、第十三卷前 4 章无冲突。
