# 灵潮修仙录 · 插画素材清单与 AI 绘画提示词

游戏里的场景和立绘目前是代码画的。把下面这些图生成出来发给 Claude，它会压缩、命名、放进这个文件夹，游戏就会自动换上插画；没有图的地方继续用代码画的版本，所以可以一张一张慢慢补。

## 怎么生成

- 工具：即梦、豆包、通义万相、可灵、Midjourney 都行。用你自己生成的图，不要用别的游戏或动画的截图。
- **场景**：竖版 9:16（比如 1080×1920），画面主体放在中间，上下留一点天空和地面，游戏会按屏幕裁切。
- **立绘**：竖版 4:5（比如 1024×1280），半身到大腿，人物居中，**纯色背景**。生成后抠图成透明 PNG（即梦自带抠图；iPhone 相册里长按人物可以直接「拷贝主体」）。
- 每张图在提示词后面都加上这一句通用风格，保证整套画风统一：

> 通用风格：国风仙侠游戏插画，厚涂，电影级光影，细腻笔触，色彩通透，高清细节，构图大气，无文字，无水印，无边框

- 生成好以后，直接在对话里发图，并说明是哪一张（写下面的文件名就行）。
