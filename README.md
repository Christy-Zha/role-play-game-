# 灵潮修仙录

末日 × 仙侠的手机网页 RPG。静态网页，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

**在线游玩**：https://christy-zha.github.io/role-play-game-/

## 玩法

画面是国风手绘 2.5D：斜视角地图、手绘质感的大头小人和妖兽、柔和光影，参考《仙剑奇侠传》《金庸群侠传》这类单机 RPG——在地图上走动、和人说话、碰到妖兽进入回合制战斗。所有画面都由代码实时绘制，不依赖外部图片。

- **江湖（大地图行走）**：点地面寻路，点人物对话。头上有「!」的人有委托，「?」的人在等你回话。从青石站东头的楼梯出站，打开地图选择去处。
- **11 个区域**：人间 8 处（废弃地铁站、锈蚀高架、旧城妖林、沉没港口、坠星研究所、天坑、灵源核心、灵源深渊），飞升后还有天外 3 处（星海残域、天庭遗迹、归墟）。每次进入随机生成，有游荡妖兽、宝箱、奇遇、陷阱、篝火，偶尔还有隐藏的「裂隙」秘境。
- **回合制战斗**：攻击、法术、神通、道具、防御、逃跑，可开「自动」（自动也会打连携）。部分首领濒死时会变身「真身」二阶段。零号、周烈可以入队。
- **连战首领**：江湖页「连战」按钮，选一个打过的首领连续挑战，手动或自动都行，每场之间自动回复两成，随时收手，结束时汇总收益。
- **小游戏**：五子棋（初/中/高三档 AI，难度越高奖励越好）、押大小、比点数、三匣（选完会问你换不换）、记忆翻牌。散落在 NPC、委托、奇遇和剧情里，最终决战也能用一盘棋定胜负。
- **家族**：主线推进到筑基后可以立族、起名。招收族人（资质有高有低，偶尔有被埋没的天才，也偶尔混进内鬼），修建祠堂、灵田、丹房、炼器坊、藏经阁、演武场，按现实时间派族人外出历练。
- **物品**：五个装备部位（兵器、护甲、佩饰、戒指、法宝），随机词条（吸血、暴伤、破甲、闪避……），宝石镶嵌与合成，功法秘籍（学会新法术或永久心法），每个首领一件传说装备。
- **选择有后果**：主线里的每个选择都会改变后面的走向——救不救阿禾决定她能不能修仙；在雾港放人还是拿灵石，决定李婶是开药铺还是变成实验体；信不信红姐、怎么对待周烈、留不留陈默，都会引出完全不同的章节、战斗和结局台词。
- **缘分**：十几位角色各有好感度，聊天、送礼（投其所好涨得更多）、做委托和剧情选择都会改变它。好感够了会触发专属剧情，可以结义、拜师、认作家人，或与红姐、周烈、苏绾、宁玄、陈默中的一位结为道侣——道侣双修加速修炼，并随你出战。
- **剧情**：两卷主线加十几段插曲与支线，带分支选择和多个结局。新人物：棋痴沈棋、赌鬼钱三、天生灵目的林小满、鬼市商人鬼手、天外来客苏绾、天穹会主宁玄……渡劫之后才发现，灵潮只是更大星海里的一块田。
- **出其不意**：宝箱怪、首领二阶段、隐藏秘境、只在夜里出摊的鬼手、刺客夜袭、无名剑客拦路，以及随机出现的「天象」（灵雨、血月、财星、妖兽潮、福星）。
- **境界即玩法**：每个大境界都解锁新能力，而不只是数值变大——筑基御剑飞行（妖兽追不上你）、金丹祭炼本命法宝、元婴元神出窍（看见隐秘之物、死而复生一次）、化神展开领域、炼虚虚空遁、合体法相天地、大乘言出法随。突破时有天地异象、属性跳变与解锁一览；金丹起每个大境界都要渡雷劫，失败会散功受伤。
- **流派搭配**：测灵根（金木水火土，外加稀有的雷、冰异灵根），五行相克，灼烧、感电、潮湿、霜冻、缠绕、破甲等状态，以及爆燃、导电、碎冰、燎原、冰封、震荡、蒸腾七种连携；配合阵法（金刚、聚灵、天罡、五行轮转、两仪、九宫）、符箓和同伴的五行，靠搭配就能越级打宗主。
- **活着的江湖**：现实日期按设备当地时钟同步，江湖历练年与现实日历独立。闭关可选1周、1个月、3个月、半年及1～100年，消耗灵石并立即结算。NPC 有自己的境界、寿元、心愿和恩怨：好友会老去、离世，被你得罪的人会变强回来寻仇，救下的孩子多年后可能成为一谷之主，斩了魔修，他逃走的徒弟也许几十年后会血洗你的宗门。
- **坊市与宗门**：南街坊市有丹铺、器铺、符箓铺、拍卖行（和江湖人物竞价）、悬赏榜、擂台和江湖榜；六大宗门各有门道，三阵连胜后可以结盟、强取或吞并，每个选择都有后果。
- **长线目标**：炼丹宗师（丹徒到丹圣）、开宗立派、收徒传承（弟子会自己冲关，也会陨落、留下遗泽，甚至叛出师门）、寻回五块残图开启上古仙府。元婴时择道：正道、魔道、隐居、宗门，加上丹道和仙府，共六种道果结局。界面上始终有「近 · 中 · 远」三层目标。
- **隐藏剧情**：剑冢、站台上的女孩、灵根之秘（双灵根）、面具之下、谷主、杀师之仇、天穹秘辛、上古仙府——只有特定的机缘和选择才会触发。
- **长期玩**：离线闭关收益、家族产出、灵源深渊无尽层、大罗圆满后轮回重修（永久加成）、3 个存档位。

## 在手机上玩

在 iPhone Safari 里打开在线地址，点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

支持 3 个存档位，可以同时养几个角色。点击右上角固定的「存档」入口，可导出备份、导入存档码，或切换、新开、删除存档；返回时会回到原页面的位置。存档保存在浏览器本地，清理 Safari 数据会丢档，请将导出的存档码保存到备忘录。

「卷宗」优先展示当前委托和新剧情；缘分与声望、已读篇章、未解锁篇章可以分别展开查看。

## 本地运行

在项目目录运行 `python -m http.server 8786`，打开 `http://127.0.0.1:8786/`。部署时需同时包含 `index.html`、`novels.js` 与 `art/`。


## 2026-11-08 小说主线与现实时间更新

- 江湖底部「小说主线」或卷宗「灵潮长路」进入第三至第十卷。八份本机已保存小说初稿共134章，可逐章阅读；32个任务节点按卷顺序推进，含现场勘察、同伴协商、行装整理、任务执行、补给与结果记录。不是新增32张可走动地图或134场战斗。
- 小说路线拥有独立的同伴协作记录与连续性，不重置原游戏的角色、装备、自由江湖分支、道侣或存档。原稿采用的多年跨度不修改现实日历。初稿之间尚未统一的绝对年表不作定论。
- 原稿文件名、SHA-256与章数见 `sources.json`，正文保存在 `novels.js`。第十一卷、其余十二处航点、灵潮总起源等未提供内容没有续写。
- 屏幕日期每秒从设备当地时钟读取，刷新、切档和前后台恢复均同步；离线不会再让人物按六分钟一年衰老。设备时钟有误时显示也会相应变化，没有联网校时或防作弊承诺。
- 聊天和送礼都没有按日冷却。每人前5次聊天+3，之后10次+2，再之后+1。同种礼物每3次降低一档收益，最低+1；灵石价格不减，好感上限100。计数随存档保存，刷新不重置。
- 闭关是立即结算的修炼模拟，无需现实等待：周=7天、月=30天、3个月=90天、半年=180天。灵石成本与天数成比例，收益受当前境界瓶颈限制，满瓶颈不扣款。累计365天推进一个江湖历练年，不改变现实日期、伤势结束时间、家族派遣或玉简温养倒计时。旧存档历练年与累计闭关年保留。
- 旧版突破时的多年修炼保留为「突破历练」，也不改变现实日期。
