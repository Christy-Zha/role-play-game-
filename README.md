# 灵潮修仙录

末日 × 仙侠的手机网页 RPG。静态网页，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

**在线游玩**：https://christy-zha.github.io/role-play-game-/

## 玩法

画面是国风手绘 2.5D：斜视角地图、手绘质感的大头小人和妖兽、柔和光影，参考《仙剑奇侠传》《金庸群侠传》这类单机 RPG——在地图上走动、和人说话、碰到妖兽进入回合制战斗。

- **正史以卷宗为准**：第一到第十卷（青石、雾港、坠星、河灯、太一、分山、天隙、归潮、远岸……）是唯一的主线。旧版里和它打架的章节（雾港白旗船、槐下、堕仙、灵源终章、飞升、星海、天庭、归墟、人间篇等）都已撤下。第十一卷在写，终局会按你的选择分成几种。
- **江湖（大地图行走）**：点地面寻路，点人物对话。头上有「!」的人有委托。从青石站东头的楼梯出站，打开地图选择去处。
- **8 个区域**：废弃地铁站、锈蚀高架、旧城妖林、沉没港口、坠星研究所、天坑、灵源核心、灵源深渊。每次进入随机生成，有游荡妖兽、宝箱、奇遇、陷阱、篝火，偶尔有隐藏的「裂隙」秘境。
- **回合制战斗**：攻击、法术、道具、防御、逃跑，可开「自动」。**剧情战有规矩**：寄焰藤不许用火、护炉架要先锁住、晶背蛾追灵息、衡渡身边的镜中错影会替他挡刀、负碑鼋撑过六回合就退……战斗开始会提示。
- **一键扫荡**：打败过首领的地方可以一键清图（×1/×5/×10）。每遍花三天；同一处扫得太勤，「灵脉余量」下降、收获变少，歇几天或换个地方就会回来。想亲自看着打首领，扫荡面板里有「连战首领」。
- **小游戏**：五子棋、押大小、比点数、三匣、记忆翻牌，散落在 NPC、委托和奇遇里。
- **行社**：第二卷青石行社挂牌后开启。招人、修建议事堂、灵田、丹房、炼器坊、藏经阁、演武场，派人外出——都按游戏里的日子算。
- **物品**：五个装备部位，随机词条，宝石镶嵌与合成，功法秘籍。行囊有「整理」：一键卖掉凡品/灵品、把较弱的装备拆成材料，或打开「自动卖凡品」。
- **选择有后果**：筑基丹给谁、阿禾的蓝线怎么压、河边停不停下来取水样、伏灯站认不认得出灯号……「卷宗」底下的**因果录**记着你做过的每个选择，后面几卷也会提起它们。
- **缘分与道侣**：聊天、送礼（随时可以，收益递减）、委托和剧情选择都会改变好感，好感够了触发专属剧情。可以结义、拜师、认作家人；道侣最多三位，可选红鹞、周烈、萧尘、苏绾。第五卷那顿夹生的晚饭会和红鹞走到一起（道侣位满了就不会）。有几位道侣，后面几卷开头就有几个人送你出门。
- **境界**：炼气一层到筑基大圆满。金丹这一关留给第十一卷，修为攒满了不会浪费。
- **日子只随你的行动走**：出城历练、扫荡、闭关、歇息、剧情里的「过些日子」都会让日子往前走；你不玩的时候世界停着，不会错过谁。
- **长期玩**：灵源深渊无尽层、行社经营、3 个存档位。

## 在手机上玩

在 iPhone Safari 里打开在线地址，点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

支持 3 个存档位，可以同时养几个角色。点击右上角固定的「存档」入口，可导出备份、导入存档码，或切换、新开、删除存档；返回时会回到原页面的位置。存档保存在浏览器本地，清理 Safari 数据会丢档，请将导出的存档码保存到备忘录。

「卷宗」优先展示当前委托和新剧情；缘分与声望、已读篇章、未解锁篇章可以分别展开查看。

## 本地运行

在项目目录运行 `python -m http.server 8786`，打开 `http://127.0.0.1:8786/`。部署时需同时包含 `index.html`、`novels.js` 与 `art/`。`novels.js`（旧卷原文，约 600KB）只在卷宗里点开「旧卷」时才下载。


## 2026-11-08 第二次更新

1. **统一世界观**：以第一到第十卷为正史，冲突的旧章节、旧委托（阿禾妈妈的白旗船、给零号起名、陈默的妹妹、星海天庭……）撤下；红姐统一叫红鹞，零号统一叫初一；家族改为卷宗里的「青石行社」；江湖里去掉了吞并宗门、吞噬修为、血洗行社。
2. **剧情战有规矩**，新敌人有了自己的造型（插画清单见 Claude Docs「插画清单（第二批）」）。
3. **因果录**：卷宗底部列出你做过的选择；第四、六、七、八、九、十卷开头会提到前面的选择。
4. **读剧情**：回顾（翻看本章说过的话和你的选择）、自动播放、文字速度（慢/中/快/瞬）、读过的章节可「快进」、没读过的要连点两下才跳过；每卷开头有前情提要；没有立绘的人物显示印章头像。
5. **一条时间线**：灵潮纪年从三年开始，日子只随行动推进，与现实时钟无关；剧情里「三年后」之类会把日历推过去。伤势、行社派遣、铁叔的补给都按游戏日子算。
6. **扫荡**有了时间成本和灵脉余量；行囊可以批量整理；连战并进扫荡面板。
7. **修炼节奏**：亲自历练一趟约得本境界两成半修为；闭关最省事但同样的日子只有历练的五分之一左右；境界停在筑基大圆满。
8. **界面**：弹窗打开时提示挪到屏幕下方、读剧情时挪到标题下面；新功能一样一样开，开的时候给一句说明；`novels.js` 改为按需加载；走过一段路、又一个多月没导出时，提醒备份存档码。
9. **多道侣**：红鹞的感情线和道侣系统合一；萧尘、苏绾有了完整的缘分剧情；多位道侣在后几卷都有台词。

**旧存档不再兼容**：打开旧版存档时，游戏会把它原样存成一份存档码（「存档」页的「旧版存档备份」里可以复制），然后开新档。

验证：`node test-game.cjs`（日历与现实时钟无关、日子只随行动走、伤势按天、补给按七天、剧情跳年、闭关、社交收益、旧章节撤下、旧卷按需加载，共 15 项）和 `node test-art.cjs`。
