# 灵潮修仙录

末日 × 仙侠的手机网页放置 RPG。单个 HTML 文件，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

## 玩法

- **修炼**：点丹田引气。小境界自动突破，跨大境界（炼气 → 筑基 → 金丹 → … → 渡劫）要亲手冲关，有失败风险，破境丹可以提高成功率。
- **历练**：7 个区域，每个区域斩妖 10 只后可以挑战首领。击败首领开启下一个区域，并打破对应的境界瓶颈。支持自动斩妖。
- **剧情**：序章加 8 章，带分支选择。选择影响「道心」：仁心强化治疗与冲关，魔心提高暴击。结局随道心变化。
- **装备与功法**：凡、灵、宝、仙四档装备；吐纳、引气、御剑、金刚、聚灵五种功法。
- **长期玩**：离线闭关收益、灵源深渊无尽层、渡劫圆满后飞升轮回（永久加成）。

## 在手机上玩

用 GitHub Pages 打开后，在 iPhone Safari 里点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

存档保存在浏览器本地。清理 Safari 数据会丢档，可以在「功法」页导出存档码备份。

## 本地运行

直接用浏览器打开 `index.html`。
