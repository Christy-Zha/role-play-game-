# 灵潮修仙录

末日 × 仙侠的手机网页 RPG。单个 HTML 文件，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

**在线游玩**：https://christy-zha.github.io/role-play-game-/

## 玩法

画面是 2.5D 斜视角像素风，参考《仙剑奇侠传》《金庸群侠传》这类单机 RPG：在地图上走动、和人说话、碰到妖兽进入回合制战斗。所有画面都由代码实时绘制，不依赖外部图片。

- **江湖（大地图行走）**：点地面寻路，点人物对话。头上有「!」的人有委托，「?」的人在等你回话。从青石站东头的楼梯出站，打开地图选择去处。
- **11 个区域**：人间 8 处（废弃地铁站、锈蚀高架、旧城妖林、沉没港口、坠星研究所、天坑、灵源核心、灵源深渊），飞升后还有天外 3 处（星海残域、天庭遗迹、归墟）。每次进入随机生成，有游荡妖兽、宝箱、奇遇、陷阱、篝火，偶尔还有隐藏的「裂隙」秘境。
- **回合制战斗**：攻击、法术、丹药、防御、逃跑，可开「自动」。部分首领濒死时会变身「真身」二阶段。零号、周烈可以入队。
- **连战首领**：江湖页「连战」按钮，选一个打过的首领连续挑战，手动或自动都行，每场之间自动回复两成，随时收手，结束时汇总收益。
- **小游戏**：五子棋（初/中/高三档 AI，难度越高奖励越好）、押大小、比点数、三匣（选完会问你换不换）、记忆翻牌。散落在 NPC、委托、奇遇和剧情里，最终决战也能用一盘棋定胜负。
- **家族**：主线推进到筑基后可以立族、起名。招收族人（资质有高有低，偶尔有被埋没的天才，也偶尔混进内鬼），修建祠堂、灵田、丹房、炼器坊、藏经阁、演武场，按现实时间派族人外出历练。
- **物品**：五个装备部位（兵器、护甲、佩饰、戒指、法宝），随机词条（吸血、暴伤、破甲、闪避……），宝石镶嵌与合成，功法秘籍（学会新法术或永久心法），每个首领一件传说装备。
- **剧情**：两卷主线加十几段插曲与支线，带分支选择和多个结局。新人物：棋痴沈棋、赌鬼钱三、天生灵目的林小满、鬼市商人鬼手、天外来客苏绾、天穹会主宁玄……渡劫之后才发现，灵潮只是更大星海里的一块田。
- **出其不意**：宝箱怪、首领二阶段、隐藏秘境、只在夜里出摊的鬼手、刺客夜袭、无名剑客拦路，以及随机出现的「天象」（灵雨、血月、财星、妖兽潮、福星）。
- **长期玩**：离线闭关收益、家族产出、灵源深渊无尽层、大罗圆满后轮回重修（永久加成）、3 个存档位。

## 在手机上玩

在 iPhone Safari 里打开在线地址，点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

支持 3 个存档位，可以同时养几个角色，在「卷宗」页最下面切换、新开或删除。存档保存在浏览器本地。清理 Safari 数据会丢档，可以在「卷宗」页导出存档码备份。

## 本地运行

直接用浏览器打开 `index.html`。
