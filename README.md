# 灵潮修仙录

末日 × 仙侠的手机网页 RPG。单个 HTML 文件，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

**在线游玩**：https://christy-zha.github.io/role-play-game-/

## 玩法

画面是 2.5D 斜视角像素风，参考《仙剑奇侠传》《金庸群侠传》这类单机 RPG：在地图上走动、和人说话、碰到妖兽进入回合制战斗。所有画面都由代码实时绘制，不依赖外部图片。

- **江湖（大地图行走）**：点地面，主角自己寻路走过去；点人物上前对话，头上有「!」的人有委托，「?」的人在等你回话。墨老的残魂会一直跟在身后。从青石站东头的楼梯出站，打开城区地图选择要去的地方。
- **8 个区域**：废弃地铁站、锈蚀高架、旧城妖林、沉没港口、坠星研究所、天坑、灵源核心、灵源深渊，每个都有自己的地形、光影和天气粒子。每次进入随机生成，路上有游荡的妖兽、宝箱、奇遇光点、陷阱和篝火，尽头的祭坛守着首领。
- **回合制战斗**：碰到妖兽切入战斗画面。指令有攻击、法术、丹药、防御、逃跑，也可以开「自动」。法术随境界解锁：御剑术、回春术、剑气横扫、金刚护体、太一雷诀、万剑归宗。完成委托后，零号和周烈会加入队伍并肩作战。
- **修炼**：点击画面引气入体。小境界自动突破，跨大境界（炼气 → 筑基 → 金丹 → … → 渡劫）要亲手冲关，有失败风险，并且要先击败对应区域的首领。
- **奇遇与委托**：二十多个带抉择的随机事件；铁叔、阿禾、红姐、墨老等人的委托链（例如帮阿禾寻找失踪的妈妈、守住青石站抵御尸潮）。
- **玉简洞天**：把丹药、装备、灵石放上玉台温养，按现实时间成熟。每次收取都会让灵光外泄，外泄满了，天穹会的追兵会找上门。
- **剧情**：视觉小说式演出，二十多幕带立绘和场景的剧情，有分支选择，影响「道心」和结局。
- **长期玩**：离线闭关收益、灵源深渊无尽层、渡劫圆满后飞升轮回（永久加成）。

## 在手机上玩

在 iPhone Safari 里打开在线地址，点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

支持 3 个存档位，可以同时养几个角色，在「卷宗」页最下面切换、新开或删除。存档保存在浏览器本地。清理 Safari 数据会丢档，可以在「卷宗」页导出存档码备份。

## 本地运行

直接用浏览器打开 `index.html`。
