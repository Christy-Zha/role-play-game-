# 灵潮修仙录

末日 × 仙侠的手机网页 RPG。单个 HTML 文件，不用安装，手机浏览器打开就能玩。

> 二〇四九年，天空裂开，沉寂三千年的灵气倒灌人间。三年后，你是地铁避难所里的一个拾荒者，捡到一枚住着三百年前修士残魂的玉简。

**在线游玩**：https://christy-zha.github.io/role-play-game-/

## 玩法

- **修炼**：点击画面引气入体。小境界自动突破，跨大境界（炼气 → 筑基 → 金丹 → … → 渡劫）要亲手冲关，有失败风险。
- **斩妖**：7 个手绘场景区域，30 多种妖兽造型。斩妖 10 只后挑战首领，打败首领开启下一个区域，并打破对应的境界瓶颈。支持自动斩妖。
- **玉简洞天**：把丹药、装备、灵石放上玉台温养，按现实时间成熟。丹药翻倍，装备升品，灵石增值。每次收取都会让灵光外泄，外泄满了，天穹会的追兵会找上门。
- **剧情**：视觉小说式演出，二十多幕带立绘和场景的剧情，有分支选择。选择影响「道心」和结局，包括宿敌周烈的命运。
- **长期玩**：离线闭关收益、灵源深渊无尽层、渡劫圆满后飞升轮回（永久加成）。

## 在手机上玩

在 iPhone Safari 里打开在线地址，点「分享 → 添加到主屏幕」，就能像 App 一样全屏打开。

存档保存在浏览器本地。清理 Safari 数据会丢档，可以在「功法」页导出存档码备份。

## 本地运行

直接用浏览器打开 `index.html`。
